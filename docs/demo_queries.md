# Focused queries for the FalkorDB browser

Open <http://localhost:3000>, log in with the password from `.env`, choose the `lineage` graph and paste a query. The whole graph is a hairball; these return small, readable subgraphs. Generated by `python -m lineage.graph.demo_queries`.

## 1. The hero path: a docs label, its feature gate and the gate's stage in every release

Resource Quotas page -> section -> the 'alpha since v1.8' claim -> the gate it is about -> one STAGE_IN edge per release (alpha 1.7, beta 1.10, stable 1.25).

```cypher
MATCH (p:DocPage {path:'content/en/docs/concepts/policy/resource-quotas.md'})-[r1:HAS_SECTION]->(s:DocSection {anchor:'quota-for-local-ephemeral-storage'})-[r2:HAS_CLAIM]->(c:Claim)-[r3:ABOUT]->(g:FeatureGate)-[r4:STAGE_IN]->(rel:Release)
WHERE r3.method = 'manual'
RETURN p, r1, s, r2, c, r3, g, r4, rel
```

## 2. The finding, the decision behind it and the team that owns it

The detector's Finding node, the claim and gate it points at, the design document (KEP) that introduced the gate, and its owning team.

```cypher
MATCH (f:Finding {active:true})-[r1:FOR_CLAIM]->(c:Claim {id:'content/en/docs/concepts/policy/resource-quotas.md#quota-for-local-ephemeral-storage:1'}), (f)-[r2:FOR_GATE]->(g:FeatureGate), (f)-[r3:AS_OF]->(rel:Release)
OPTIONAL MATCH (k:KEP)-[r4:INTRODUCES]->(g) WHERE r4.confidence >= 0.7
OPTIONAL MATCH (k)-[r5:OWNED_BY]->(t:SIG)
RETURN f, r1, c, r2, g, r3, rel, r4, k, r5, t
```

## 3. How the link was made, and what a human did

Both sibling gates were candidates at 0.79 each; the project owner verified the link by hand. The edge keeps the linker's own score.

```cypher
MATCH (c:Claim {id:'content/en/docs/concepts/policy/resource-quotas.md#quota-for-local-ephemeral-storage:1'})-[a:ABOUT]->(g:FeatureGate)
RETURN c, a, g
```

## 4. One gate's lifecycle

LocalStorageCapacityIsolation across releases.

```cypher
MATCH (g:FeatureGate {name:'LocalStorageCapacityIsolation'})-[e:STAGE_IN]->(r:Release)
RETURN g, e, r
```

## 5. Ownership time travel: who approved the Job controller, and when

Edges carry valid_from / valid_to as sampled release numbers: alculquicondor 130-132, mimowo from 132. Click an edge to see its properties and source_url.

```cypher
MATCH (p:Person)-[a:APPROVER_OF]->(c:CodePath {id:'kubernetes:pkg/controller/job'})
RETURN p, a, c
```

## 6. One team's ownership: sig-storage, the code it owns, who approves it

SIG -> OWNS -> CodePath <- APPROVER_OF - Team <- MEMBER_OF - Person (people resolved through the team alias, current members only).

```cypher
MATCH (s:SIG {id:'sig-storage'})-[o:OWNS]->(c:CodePath)
OPTIONAL MATCH (t:Team)-[a:APPROVER_OF]->(c) WHERE a.valid_to IS NULL
OPTIONAL MATCH (p:Person)-[m:MEMBER_OF]->(t) WHERE m.valid_to IS NULL
RETURN s, o, c, a, t, m, p
```

## 7. Inheritance: a docs page's folder chain up to the root

Ownership is inherited down the tree; the walk stops at content/en because its OWNERS sets no_parent_owners. (This shows the tree; the real query cuts the walk.)

```cypher
MATCH path = (c:CodePath {id:'website:content/en/docs/concepts/policy'})-[:CHILD_OF*0..]->(anc:CodePath)
RETURN path
```

## 8. Everything the detector wants a human to look at

Findings, minor findings and review items with their reason. Use the table view.

```cypher
MATCH (f:Finding {active:true})
RETURN f.severity AS severity, f.kind AS kind, f.message AS message ORDER BY severity, kind
```
